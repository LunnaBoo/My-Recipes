The Source Serif 4 files are the static desktop TTFs from the official Adobe
release (`source-serif-4.005_Desktop.zip`, `TTF/` directory). The release spells
the 600 weight `SourceSerif4-Semibold.ttf`; it is renamed here to
`SourceSerif4-SemiBold.ttf` so the filename matches the font key used by
`expo-font`. The binary is unchanged.
